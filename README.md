Crypto Trading Platform Demo

A transparent demo trading platform prototype. It does NOT promise guaranteed returns and does not use fabricated withdrawal/testimonial records.


Run


Install Node.js 18+.

npm install

npm start

Open http://localhost:3000


Important

The payment destination is intentionally a placeholder. Replace it with a verified blockchain wallet address and network after selecting a compliant payment provider.


Demo mode uses simulated balances and bot trades. Do not use it to accept real deposits until proper KYC/AML, custody, payment-provider, security, legal, and regulatory requirements have been addressed.
